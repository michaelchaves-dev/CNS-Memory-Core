## Field Definitions

- **Frequency** — Daily / Weekly / Monthly / Ad hoc
- **Time spent** — Estimated hours per occurrence
- **Data involved** — Types of data touched (emails, docs, CRM, financials, etc.)
- **Approval needed?** — Does output require human sign-off before use?
- **Can Claude help?** — Yes / Partial / No (flag reason if No)
- **Can MCP help later?** — Could an MCP tool (calendar, CRM, drive) automate handoffs?

---

## Prioritization Guide

Score each workflow 1–3 on each dimension, then sum:

| Dimension | 1 (Low) | 2 (Medium) | 3 (High) |
|---|---|---|---|
| Frequency | Monthly | Weekly | Daily |
| Time savings | < 30 min | 30–120 min | > 2 hrs |
| Claude fit | Partial | Good | Excellent |
| Data safety | Sensitive | Mixed | Clean |

**Total ≥ 9** → Build first. **6–8** → Build next round. **< 6** → Defer.
